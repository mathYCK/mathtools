直接在圖上拖曳  C  點,可在 a+b 不變下改變分配。

為什麼成立？

以 AB 為直徑作半圓,C 在 AB 上,AC = a、CB = b。過 C 作垂線交半圓於 D。

因為 △ACD ∼ △DCB(半圓內的直角),得 CD / AC = CB / CD,所以 CD = √(a·b)——這是高,也就是幾何平均。

而半圓半徑 OD = (a+b)/2,是固定的算術平均。在直角三角形 OCD 中,斜邊 OD 永遠不短於直角邊 CD,故 (a+b)/2 ≥ √(ab),當且僅當 C 落在圓心 O(即 a = b)時取等號。
