單元 05　直線方程式　›　己　二元一次不等式
二元一次不等式 Linear Inequality in 2 Variables
這一頁要搞懂：不等式代表半平面 → 用測試點決定區域 → 多個不等式取交集。
幾何意義
ax + by + c > 0（或 < 0）代表直線 ax + by + c = 0 的某一側半平面。直線把平面切成兩半：一半代入後都 > 0，另一半代入後都 < 0，直線上剛好 = 0。
畫圖三步驟
  • ▸畫出邊界直線（>, < 畫虛線，不含邊界；≥, ≤ 畫實線，含邊界）。
  • ▸取一個測試點（常用原點 (0,0)）代入，成立就取該側，不成立取另一側。
  • ▸若直線通過原點，原點不能當測試點，改用 (1,0) 或 (0,1)。
小技巧（不用測試點）：當 b > 0 時，ax + by + c > 0 ⟺ 點在直線上方；< 0 ⟺ 下方。b < 0 時上下相反。
理由：b > 0 時，by > −ax − c ⟺ y > (−ax − c)/b，也就是比直線上同一個 x 的點還高。
例題
例 1x + y − 2 > 0
  1. 邊界 x + y − 2 = 0，過 (2,0)、(0,2)；不等號 > ⟹ 虛線。
  2. 代入 (0,0)：−2 > 0 為假 ⟹ 取不含原點那一側（右上方）。
  3. 驗算：b = 1 > 0 且是 > 0 ⟹ 直線上方 ✔
例 22x − y + 4 ≥ 0
  1. 邊界 2x − y + 4 = 0，過 (−2,0)、(0,4)；≥ ⟹ 實線。
  2. 代入 (0,0)：4 ≥ 0 為真 ⟹ 取含原點那一側（右下方）。
  3. 驗算：b = −1 < 0，≥ 0 ⟹ 直線下方 ✔
例 3x ≤ 3
  1. 邊界是鉛直線 x = 3；≤ ⟹ 實線。
  2. 代入 (0,0)：0 ≤ 3 為真 ⟹ 取左側。
  3. 規律：只有 x 的不等式切成左右；只有 y 的切成上下。
例 4x − 2y < 0
  1. 邊界 x − 2y = 0 通過原點；< ⟹ 虛線。
  2. 代入 (0,0) 得 0 < 0：原點在線上，無法判斷！
  3. 改用 (0,1)：0 − 2 = −2 < 0 為真 ⟹ 取含 (0,1) 那一側（左上方）。
例 5x + y ≤ 4，x ≥ 0，y ≥ 0（聯立）
  1. 三個不等式各自畫出半平面，再取交集（重疊的部分）。
  2. x ≥ 0 是 y 軸右側、y ≥ 0 是 x 軸上方、x + y ≤ 4 是直線下方。
  3. 交集為三角形（含邊界），頂點 (0,0)、(4,0)、(0,4)。測試 (1,1)：2 ≤ 4、1 ≥ 0、1 ≥ 0 全成立 ✔
互動實驗室
拉動 a, b, c 的拉桿、切換不等號，拖曳測試點 P，看看解區域怎麼變。動手試試：
  1. 按範例「x − 2y < 0」，測試點放在原點，看提示說什麼？
  2. 按「旋轉直線」：藍色箭頭（法向量 (a, b)）永遠指向哪一側？
  3. 選「x + y − 2 > 0」後按「平移直線」：c 變成多少時，原點會跑進解區域？
隨堂檢測
Q1　3x − 2y + 6 < 0 的解區域含不含原點？邊界畫實線還是虛線？
代入 (0,0)：6 < 0 為假 ⟹ 不含原點；不等號 < ⟹ 虛線。
Q2　點 (2, −1) 是否在 2x + y − 1 ≥ 0 的解區域內？
2(2) + (−1) − 1 = 2 ≥ 0 成立 ⟹ 是。
Q3　y ≤ −2x + 1 是直線的上方還是下方？
移項成 2x + y − 1 ≤ 0，b = 1 > 0 且 ≤ 0 ⟹ 下方（含直線）。
